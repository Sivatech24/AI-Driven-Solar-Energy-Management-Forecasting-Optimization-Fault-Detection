🔋🌞 Solar Power Setup Guide with Arduino + ESP32

Goal: Power your Arduino and ESP32 from a 12V solar system, measure battery voltage, temperature, and humidity using DHT22, and send data via ESP32.

🧰 Components

⚠️ SAFETY FIRST: Never short the battery. Connect battery to the PWM first. Check polarities and voltages carefully.

🪛 Step 1: Solar Panel, Battery & PWM Charge Controller

Connections:

FromTo
Solar Panel +PWM Solar +
Solar Panel −PWM Solar −
Battery +PWM Battery +
Battery −PWM Battery −

Multimeter Check:

  • Battery connected → PWM lights on.
  • In sunlight → PWM shows charging.
  • PWM Load output should be ~12V.

🔋 Step 2: Connect LM2596 Buck Converter

Connections:

LM2596 PinConnects To
IN+PWM Load +
IN−PWM Load −

Adjust output with a multimeter to exactly 5.0V using the onboard potentiometer.

⚡ Step 3: Power Arduino and ESP32

LM2596 OutputConnects To
OUT+ (5V)Arduino 5V, ESP32 5V
OUT− (GND)Arduino GND, ESP32 GND

🌡️ Step 4: Connect DHT22 Sensor

DHT22 PinConnects To
1 (VCC)Arduino 5V
2 (Data)Arduino D2
4 (GND)Arduino GND

Connect 10kΩ pull-up resistor between Pin 1 and Pin 2.

🔋 Step 5: Battery Voltage Divider

  • 20kΩ: Battery + to Node
  • 10kΩ: Node to GND
  • Node to Arduino A0

Node voltage should be ≤ 5V.

🔁 Step 6: Arduino to ESP32 Serial (UART)

  • Arduino TX → 1kΩ → Node → ESP32 RX (GPIO16)
  • Node → 2kΩ → GND
  • Connect all grounds together

📜 Step 7: Arduino Code

#include <DHT.h>
#define DHTPIN 2
#define DHTTYPE DHT22
#define VOLTAGE_PIN A0

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  int rawADC = analogRead(VOLTAGE_PIN);
  float v = rawADC * 5.0 / 1023.0;
  float battVoltage = v * 3.0;

  Serial.print(t); Serial.print(",");
  Serial.print(h); Serial.print(",");
  Serial.println(battVoltage);
  delay(2000);
}

📜 Step 8: ESP32 Code

#define RXD2 16
#define TXD2 17

void setup() {
  Serial.begin(115200);
  Serial2.begin(9600, SERIAL_8N1, RXD2, TXD2);
}

void loop() {
  if (Serial2.available()) {
    String data = Serial2.readStringUntil('\n');
    Serial.println("From Arduino: " + data);
  }
}

🧪 Final Testing

  • Check LM2596 Output = 5.0V
  • Check voltage divider node <= 5V
  • Open Serial Monitor on ESP32 → See Arduino data
